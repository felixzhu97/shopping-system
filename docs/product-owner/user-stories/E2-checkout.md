# E2 结账

← [用户故事地图](../User-Story-Map.md)

## 背景

顾客从购物车创建订单并完成支付。

---

## US-02 下单与支付

**As a** 顾客  
**I want** 提交订单并通过支付网关付款  
**So that** 我可以完成购买

### 验收标准

1. **Scenario** 创建订单
   **GIVEN** 购物车非空且用户已登录或允许结账身份  
   **WHEN** 确认结账  
   **THEN** 创建 Order 记录

2. **Scenario** 发起支付
   **GIVEN** 订单待支付  
   **WHEN** 选择支付方式并确认  
   **THEN** 调用支付网关或 Stripe  
   **AND** 成功后订单状态更新

### 状态

规划中
