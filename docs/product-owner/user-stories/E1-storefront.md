# E1 店面

← [用户故事地图](../User-Story-Map.md)

## 背景

顾客需要发现商品并加入购物车。

---

## US-01 浏览与加购

**As a** 顾客  
**I want** 浏览商品列表与详情并加入购物车  
**So that** 我可以挑选想买的商品

### 验收标准

1. **Scenario** 浏览列表
   **GIVEN** 目录中有上架商品  
   **WHEN** 打开商店首页  
   **THEN** 看到商品列表

2. **Scenario** 加购
   **GIVEN** 用户在商品详情页  
   **WHEN** 选择数量并加入购物车  
   **THEN** 购物车反映该商品与数量

### 状态

规划中
