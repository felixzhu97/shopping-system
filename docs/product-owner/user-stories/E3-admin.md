# E3 管理

← [用户故事地图](../User-Story-Map.md)

## 背景

管理员维护商品与订单。

---

## US-03 后台运营

**As a** 管理员  
**I want** 在 Admin 管理商品与订单  
**So that** 店铺可持续运营

### 验收标准

1. **Scenario** 维护商品
   **GIVEN** 管理员已登录 Admin  
   **WHEN** 创建或更新商品  
   **THEN** 店面展示反映变更

2. **Scenario** 查看订单
   **GIVEN** 存在顾客订单  
   **WHEN** 打开订单列表  
   **THEN** 可见状态与关键字段

### 状态

规划中
