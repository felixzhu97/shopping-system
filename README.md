Shopping System brings storefront, admin, and commerce APIs together. Our mission is to help teams learn end-to-end e-commerce architecture with clear boundaries.

> Architecture docs in this meta-repo. Full application source lives in the project remote.

## Features

| Area | Capability |
|------|------------|
| **Web shop** | Browse, cart, checkout |
| **Admin** | Catalog, orders, users |
| **API** | Commerce backend (Express / TS) |
| **Auth** | OAuth (Google / GitHub) + JWT |

See the [User Story Map](docs/product-owner/User-Story-Map.md) for backlog indexing.

## Tech Stack

| Layer | Choice |
|-------|--------|
| Web | Next.js |
| Admin | Angular |
| API | Express, TypeScript, MongoDB |
| Mobile | React Native / Expo (optional) |
| Diagrams | PlantUML + C4-PlantUML |
